# 确定论文身份

用户给的线索只是起点，不是必须维护的答案。权威记录可以纠正拼写、作者次序、年份和期刊名。

## 怎么查

- 先用最强的线索：有 DOI 就 `quasi search paper --doi DOI`，否则 `quasi search paper --title 题名 --author 作者姓`。
- 读实际返回的结果，再决定下一步。候选不够时，可以改写题名、拆掉副标题、换一个作者，或者交换 DOI 和题名入口。
- 结构化来源之间说法不一，或者需要追查出版信息、稳定落地页时，用 `quasi search kagi search --format json 查询词`。
- 只要还有一条有意义的证据路径就接着查；查几次、按什么顺序，你自己判断。

## 怎么判断

最后要能说清楚四件事：这是同一篇作品；作者顺序和年份为什么成立；期刊名从哪里来；DOI 和下载链接是不是真的属于它。

- **期刊名以 Crossref 为准**，HTML 实体（如 `&amp;`）要解码。OpenAlex 有时会丢掉期刊名里有意义的标点。
- **slug** 用首位作者姓、短题名、年份组成，小写 kebab-case。

## 什么时候停下来问用户

- 最强的证据指向的作品改变了作者、年份或作品本身，或者 DOI 和用户给的不一致：把候选和证据列给用户，请他选。
- 这篇东西没有独立的出版形态，只收在某本文集、论文集里：告诉用户文集的题名、主编、出版社、年份和 ISBN，让他决定是收整本文集，还是仍按单篇处理。学会年刊、会议录里能单独检索到的单篇，以及本身就是完整出版物的讲座小册，仍按论文处理。
- 查明它是一篇普通的公开网页文章，而不是期刊论文、工作论文、会议论文、学位论文，或者有 HTML 全文的学术论文：告诉用户，并给出核实过的网址，建议按网页收录。
- 走完了所有还有价值的查询路径，仍然无法确定身份：说明查过什么，停下来。
