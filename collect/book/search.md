# 确定书的身份

用户给的线索只是起点，不是必须维护的答案。权威记录可以纠正拼写、作者次序、出版年和出版社。

## 怎么查

- 先用最强的线索：有 ISBN 就 `quasi search book --isbn ISBN`，否则 `quasi search book --title 书名 --author 作者姓`。
- 读实际返回的结果，再决定下一步。候选不够时，可以改写书名、拆掉副标题、换一个作者或编者，或者交换 ISBN 和书名入口。
- 结构化来源之间说法不一，或者需要追查出版社、版次、目录时，用 `quasi search kagi search --format json 查询词`。
- 只要还有一条有意义的证据路径就接着查；查几次、按什么顺序，你自己判断。

## 要定下来的字段

- **书名**：含副标题。
- **作者**：一律写成数组。文集写编者。
- **出版年**：你要读的这个版本的出版年。
- **出版社**。
- **ISBN**：选证据最强的一个。同一版次的精装、平装、电子版各有各的 ISBN，它们是同一本书。
- **类别**：`monograph`（专著）、`edited-volume`（文集）、`handbook`（手册），都不是就写 `other`。
- **slug**：首位作者或编者的姓、短书名、出版年，小写 kebab-case，例如 `turner-charged-2022`。

## 什么时候停下来问用户

- 候选之间作者、作品不同，或者属于不同的实质版次（修订版、重译、节译、分卷）：把候选和证据列给用户，请他选。只是 ISBN 不同、其余都一样，不算冲突，不用问。
- 走完了所有还有价值的查询路径，仍然无法确定是哪本书：说明查过什么，停下来。
