# 下载书

目标是把这本书的完整电子版，以 EPUB 或 PDF 的形式接收进 `sources/`。分析优先用 EPUB；以后要做译本则需要 PDF。

## 找候选

```sh
quasi download book candidates --title 书名 --author 作者姓 --year 出版年 --json
```

默认同时找 EPUB 和 PDF，可以用 `--format` 限定，用 `--lang en` 限定语言，也可以用 `--query` 直接写检索词。

按返回结果处理：

- **`status:"failed"`**：说明来源本身没连上，不是"没找到"。停下来告诉用户来源暂时不可用，稍后再试，并附上原始错误。
- **`status:"ok"` 但 `count:0`**：这一条检索词确实没有结果。换写法再试：去掉副标题、换一种作者写法、用 ISBN 作 `--query`。不要编造书目信息。
- **有候选**：根据书名、作者、年份、出版社、语言、格式和大小，挑出最像要找的那个版本，优先 EPUB。

## 取文件

```sh
quasi download book fetch --md5 MD5 --slug SLUG --format epub --json
```

MD5 必须是 32 位十六进制。fetch 会把文件存到临时目录，并返回路径和初步检查结果（含 `inspect.year_signals`）。

如果拿到的是 MOBI、AZW3、DjVu 等格式，可以用本机现有的工具（比如 `ebook-convert`），在同一个临时目录里转成 EPUB 或 PDF。转换本身不能证明任何事，转完要读一读，确认内容完整。

## 核对

打开书名页、版权页和几段正文，确认四件事：

- 书名、作者对得上；
- 版次对得上：同一版次只是 ISBN 不同可以接收；修订版、重译、节译、只有一卷的不收；
- 内容完整，不是试读本或节选；
- 年份：把 `year_signals`（版权年、初版年、原版年）和身份里的出版年对照。
  - 一致而且有证据支持，就继续。
  - 不一致或者说不清，就停下来问用户：保留现在的年份，还是改用文件显示的年份。把证据列出来。改用新年份会改变 slug，要回到身份那一步重新确定。

## 接收

确认无误后，只接收一个：

```sh
quasi download accept --path 临时文件路径 --slug SLUG --kind book --json
```

读返回的 `published` 路径，确认成功，然后删掉这次取回、但没有接收的临时文件。所有候选都不合适时，告诉用户试过哪些检索词、哪些候选，各自为什么不合适。
