# Topic main-agent loop acceptance

Run two actual rounds on an existing Topic. Use the released research-topic Skill,
with independent official and third-party source lanes in parallel. Partition
Archive URLs by publisher; one participant owns the shared Topic pages and the
other provides a report. After both settle, the owner merges the second report.

Observe the actual main/subagent transcript and durable files:

- Both main agents delegate bounded searches; independent questions can overlap in time.
- Selected sources enter existing material Workflows, with fresh exact completion status.
- No active Topic controller, repeated full recall, per-material outline checkpoint,
  or mandatory evidence card is required to progress to round two.
- Main may read returned sources. Synthesis receives exact files and either returns
  a report or writes its one assigned page. It does not take over research control.
- Topic resources link confirmed Archives and retain their real collection coverage;
  absent originals are reported, not treated as comprehensive saved guides.
- Record per round candidates, collected/reused sources, failures/gates, elapsed time,
  and visible context compactions. Report unobservable metrics as such.
- Resume after compaction retains question, ownership, material paths and next steps;
  do not infer context quality solely from token count.

The unit seam verifies the Skill's agent/driver references and generated artifact
contract against the schema; material and legacy Topic regression tests continue
protecting disk compatibility. They do not substitute for the Host journey above.
